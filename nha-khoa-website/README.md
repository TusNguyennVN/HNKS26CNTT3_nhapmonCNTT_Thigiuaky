# Website nha khoa

Website nha khoa là dự án **quản lý hệ thống web nha khoa**, hỗ trợ ***theo dõi log và bệnh nhân, bệnh án***. Dự án hướng đến việc quản lý dữ liệu *có tổ chức và dễ bảo trì*.

## Cấu trúc thư mục

| Thư mục | Nội dung |
|---|---|
| docs | tài liệu cập nhật|
| media | logo và hình ảnh |
| data | dữ liệu dao dịch |
| logs |  file log và báo cáo |
| backup |  bản sao lưu logo |

## Lệnh sử dụng

```powershell
Get-ChildItem -Force -Recurse
```
